# OnyxAV Gain Assist

Changes to Version 2
- Discreet Gain, Mute, Preamp code names which allows you to control three different named Components 
- Mute code name can be broken away from Gain code name in the plugin properties
- Added Disable and Invisible toggle buttons per channel
- Added a meter per channel, which can be enabled in the plugin properties - exposes a Control Pin that you can tie to a meter level out control pin. Allowing you to hide / disable the meter at the same time as your gain controls
- Changed all text entries to Combo Boxes
- Added default Preamp Preset names and values
